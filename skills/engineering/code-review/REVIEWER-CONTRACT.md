# Reviewer contract

Use only the assigned axis and captured targets, including their complete scope, seam, and validation records. For a supplied Work Tracker pack, apply [Context reading](references/bundled/federated-workflow/CONTEXT-READING.md) before reviewing. Preserve its entry path and complete linked sources. For other authority, use the supplied specification and accepted user directions without inventing a pack.

Return the governing sources actually used, with immutable revisions or content fingerprints, alongside the findings. The calling workflow records the complete Authority evidence binding and owns preparation and final freshness checks. Report unavailable required sources or inconsistent captured inputs as incomplete coverage. Inspect captured commits and, for WIP, the supplied immutable materialized diff with its snapshot ID and digest.

Review without changing repositories or provider state. Return findings and source-bound evidence to the caller. Perform no Context Assembly, provider lookup, publication, or delegation.

## Complete the selected axis

A full pass continues after every finding and finishes the complete selected axis before returning.

Audit every member of the finite input sets applicable to the selected axis: changed files; repository rules and heuristics for Standards or authoritative requirements and decisions for Spec; Settled Seams and their named providers and consumers; and supplied validation claims. Return all material findings from the full pass together. Include a **Coverage receipt** with audited/total counts for each applicable set. State why a set is not applicable. Coverage is incomplete while any item remains unaccounted for.

Counts account for inspected inputs; they do not establish correctness. Investigate behavior and support findings with the affected code, requirement, or rule.
