# Evaluate prior changes in selected work

## Establish eligibility

Use the prior-change set frozen before diagnosis or edits. Evaluate earlier implemented changes that could apply to the selected work. Keep accepted but unimplemented changes separate. For each selected change, return applicable, not applicable, or unknown with its evidence.

Use only the selected histories for new observations. Earlier journal observations can support accumulated comparisons with their recorded scope, sources, and confidence. Additional history searches need an explicitly broader retrospective scope.

## Recover time and exposure

Apply the journal's [event-time and version rules](references/JOURNAL.md#event-time-and-version) to build exposure groups for each selected change. Identify originating incidents and shared incidents across groups before including evidence in a comparison.

A long-running chat may retain earlier instructions after a file changes; inspect the available runtime loading evidence. An available instruction that the agent ignored is an observed outcome, not grounds to exclude an applicable opportunity.

Collect the journal's required [observation fields](references/JOURNAL.md#record) for applicable opportunities, including cases where no failure occurred.

## Assess the observed effect

Apply the journal's [evaluation rules](references/JOURNAL.md#evaluation) when comparing outcomes with the original expectation. Inspect repeated errors, corrections, regressions, review returns, and verification work where relevant.

Explain model, instruction, environment, and task differences that affect comparability. When changes were introduced together, report any limit on attribution to one mechanism rather than dividing a combined effect arbitrarily.

Return proposed observations, evidence and incident references, applicability and exposure groups, comparison limits, a bounded assessment, and the next evidence needed. A recommendation to revise or remove a mechanism goes to the diagnosis branch or coordinator as a proposal, without changing the accepted decision or applying a remedy.

Done when every assigned change has an evidence-backed observation, a non-applicability result, or a named evidence gap, and the comparison satisfies the journal's event-time and evaluation rules.
