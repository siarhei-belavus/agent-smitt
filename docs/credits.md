# Credits

Agent Smitty began as a customized version of [Matt Pocock's skills](https://github.com/mattpocock/skills). Matt's work established the collection's planning flow, interviewing approach, deep-module design discipline, and test-driven development workflow. This repository retains and adapts that work under its MIT license.

The local evolution adds repository-owned Code Host and Work Tracker bindings, domain federation, planning contracts, coordinated delivery across repositories, recovery records, review feedback, and closeout. Individual retained skills may also have local changes. This collection does not claim to track every upstream release.

The workflow router is named `ask-smitt`, adapted from upstream's `ask-matt` to describe this collection's setup, planning, delivery, and closeout routes.

The [PR skill's credits](../skills/engineering/pr/CREDITS.md) record its adaptation from Matt's version and the origin of its visual presentation guidance in Dex Horthy's `show-me` skill from Humanlayer. Keep that attribution with copies of the skill.

## Public repository references

The public presentation was informed by these repositories:

- [mattpocock/skills](https://github.com/mattpocock/skills), for a collection organized around an engineering workflow.
- [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills), for prominent installation instructions and descriptions of when to use each skill.
- [anthropics/skills](https://github.com/anthropics/skills), for self-contained skill directories and explicit attribution and licensing.

Installation behavior follows the [Skills CLI](https://github.com/vercel-labs/skills). These are references for repository presentation and distribution, not a claim that their workflows or agent requirements are interchangeable.
